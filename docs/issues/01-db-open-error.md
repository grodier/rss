## Problem

In `cmd/www/application.go` (`Application.Run`, ~line 33), the error from `psql.OpenDB` is discarded:

```go
db, err := psql.OpenDB(app.config.db.dsn, ...)
if err != nil {
    return nil   // <-- BUG: should return err
}
```

If Postgres is down or the DSN is wrong, `Run` returns `nil`, `main` logs nothing, and the process exits with status **0**. That hides the failure from the operator and from any process supervisor.

## Fix

Return the error, wrapped with context:

```go
if err != nil {
    return fmt.Errorf("open database: %w", err)
}
```

`main.go` already logs a returned error and calls `os.Exit(1)`, so nothing else needs to change.
