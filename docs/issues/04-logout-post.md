## Problem

`/logout` is registered as `r.Get("/logout", s.logoutHandler)` in `internal/server/router.go`, and every template's logout form uses `method="get"`. GET requests must not change state. Any third-party page, or even an `<img src="https://host/logout">`, can log a user out, and the session cookie's `SameSite=Lax` default does not stop top-level GET navigations. It also blocks the CSRF issue, because `http.CrossOriginProtection` always allows GET.

## Fix

1. `internal/server/router.go`: `r.Post("/logout", s.logoutHandler)`.
2. Change every `<form action="/logout" method="get">` to `method="post"`. Currently `discover.html`, `feed.html`, `feeds.html`, `home_auth.html`; run `grep -rn '/logout' internal/ui/templates` to be sure.
3. No handler changes are needed.
