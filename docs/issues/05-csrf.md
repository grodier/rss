## Problem

None of the POST endpoints (`/signup`, `/login`, `/feeds`, `/subscribe`, and `/logout` once it is POST) have CSRF protection. The scs session cookie defaults to `SameSite=Lax`, which blocks most cross-site POSTs in modern browsers. But that is a browser default, not an app guarantee, and it does not cover same-site/subdomain attackers or login CSRF.

**Depends on:** "Logout uses GET". `CrossOriginProtection` always allows GET, so `/logout` is not protected until it is a POST.

## Fix

Use the standard library's `http.CrossOriginProtection` (Go 1.25+; this repo is on Go 1.26). It rejects non-safe cross-origin browser requests using the `Sec-Fetch-Site` / `Origin` headers, needs no tokens, and needs no template changes. **Do not add a third-party CSRF library.**

In `internal/server/router.go`, register it right after `recoverPanic`:

```go
cop := http.NewCrossOriginProtection()
router.Use(cop.Handler) // func(http.Handler) http.Handler: plugs straight into chi
```

Optional: `cop.SetDenyHandler(...)` to render a proper 403 page with `s.renderHTML` instead of the default plain-text response. Keep the status 403.

Also harden the session cookie in `cmd/www/application.go`:

```go
sessionManager.Cookie.SameSite = http.SameSiteLaxMode           // explicit, same as the default
sessionManager.Cookie.Secure = app.config.env == "production"
```

## Tests

In `internal/server/router_test.go` (create or extend), no DB is needed. Target `POST /logout`, which touches only the session. If the logout issue hasn't landed yet, use `POST /login` with an empty form instead, which returns 422 without hitting the DB.

| Case | Headers | Expect |
|---|---|---|
| cross-site browser POST | `Sec-Fetch-Site: cross-site` | 403 |
| cross-origin via Origin | `Origin: https://evil.example` (request Host `example.com`, no Sec-Fetch-Site) | 403 |
| same-origin POST | `Sec-Fetch-Site: same-origin` | not 403 (303 logout / 422 login) |
| non-browser client | none | not 403 |
| safe method | `GET /login` with `Sec-Fetch-Site: cross-site` | 200 |

If `internal/server/testutils_test.go` doesn't exist on `main` yet, create it. No database is needed: `Services{}` holds nil repositories and `scs.New()` uses an in-memory session store.

```go
package server

import (
	"io"
	"log/slog"
	"testing"

	"github.com/alexedwards/scs/v2"
)

func newTestServer(t *testing.T) *Server {
	t.Helper()
	logger := slog.New(slog.NewTextHandler(io.Discard, nil))
	s, err := NewServer(logger, Config{Port: 4000, Env: "development"}, Services{}, scs.New())
	if err != nil {
		t.Fatal(err)
	}
	return s
}
```
