## Problem

`recoverPanic` in `internal/server/middleware.go` calls `s.serverErrorJSON`. Every user-facing page is HTML, so a panic in any page handler shows the browser a raw JSON blob (`{"error_code":"INTERNAL_ERROR",...}`) instead of `error.html`.

Confirmed: wrapping a panicking handler with `s.recoverPanic` returns `500` with `Content-Type: application/json`.

## Fix

In `recoverPanic`, call `s.serverErrorHTML(w, r, fmt.Errorf("%v", err))` instead of `serverErrorJSON`. Keep `Connection: close`. (`%v` is more correct than `%s` for arbitrary panic values.)

Out of scope: `router.NotFound` / `MethodNotAllowed` also return JSON. That's tracked separately in planning; don't change it here.
