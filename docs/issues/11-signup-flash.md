## Problem

After a successful signup, `signupFormHandler` (`internal/server/user.go`) sets:

```go
s.sessionManager.Put(r.Context(), "flash", fmt.Sprintf("User account %s created successfully at %s", id, createdAt.Format(time.RFC1123)))
```

This shows the internal UUID and a server timestamp to the user. It is debugging output that leaks an internal identifier and isn't useful to the user.

## Fix

- Replace it with a user-friendly message, e.g. `"Your signup was successful. Please log in."`.
- Discard the unused values: `_, _, err := s.services.UserService.Create(...)`. Remove the `fmt` / `time` imports if they become unused. Do **not** change the `UserRepository.Create` signature in this issue.
