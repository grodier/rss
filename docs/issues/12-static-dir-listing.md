## Problem

`internal/server/router.go` serves static files with `router.Handle("/static/*", http.FileServerFS(ui.Static))` and has a `//TODO: disable index routes`. `http.FileServer` generates directory listings, so `GET /static/` and `GET /static/css/` return 200 with a file index.

Confirmed with `httptest`: `/static/`, `/static/css/`, and `/static/css/main.css` all return 200.

## Fix

Wrap the file server so any request for a directory (path ending in `/`, or `/static` itself) returns 404 via `s.notFoundResponse`, e.g.:

```go
fileServer := http.FileServerFS(ui.Static)
router.Handle("/static/*", http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
	if strings.HasSuffix(r.URL.Path, "/") {
		s.notFoundResponse(w, r)
		return
	}
	fileServer.ServeHTTP(w, r)
}))
```

Also consider `/static/css` (no trailing slash). `http.FileServer` redirects it to `/static/css/`, which the check above then 404s; that's acceptable. Remove the TODO comment.

Optional: add a `Cache-Control` header for static assets. Keep that out unless trivial.
